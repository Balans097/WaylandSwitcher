# WaylandSwitcher — руководство пользователя

Переключатель раскладки клавиатуры для Linux/Wayland с автоматической
коррекцией текста, набранного не в той раскладке, — как набираемого прямо
сейчас, так и уже выделенного в любом приложении.

## 1. Что делает программа

WaylandSwitcher решает одну проблему: вы напечатали текст, забыв
переключить раскладку, и получили `ghbdtn` вместо «привет». Исправить это
можно двумя способами.

**Способ А — текст набирается прямо сейчас.**
Вы замечаете, что раскладка не та, и нажимаете клавишу коррекции (по
умолчанию `Pause`/`Break`). WaylandSwitcher стирает набранное, переключает
раскладку и повторяет те же нажатия клавиш.

**Способ Б — текст уже находится в документе.**
Вы выделяете готовый текст мышью, клавишами `Shift`+стрелки (а также
`Shift`+`Home`/`End`/`PageUp`/`PageDown`) или сочетанием `Ctrl`+`A` и
нажимаете ту же клавишу коррекции. Программа копирует выделение,
**перекодирует символы посимвольно** по их позиции на клавиатуре (принцип
Punto Switcher: `q`↔`й`, `w`↔`ц`, `;`↔`ж` и так далее, EN→RU или RU→EN
определяется автоматически) и вставляет результат на место выделения.
Многострочный текст поддерживается.

Системная раскладка переключается отдельной клавишей или сочетанием,
которые вы зададите при настройке (например, правый `Ctrl`).

## 2. Требования

- Linux с Wayland-сессией (GNOME/Wayland и аналоги). X11 поддерживается
  через `xclip` или `xsel` вместо `wl-clipboard`.
- Права root: служба читает `/dev/input/*` и создаёт виртуальную
  клавиатуру через `/dev/uinput`.
- Для коррекции выделенного текста — один из инструментов буфера обмена:
  - **Wayland:** `wl-clipboard` (`wl-copy`, `wl-paste`);
  - **X11:** `xclip` или `xsel`.
- Для сборки — компилятор [Nim](https://nim-lang.org/install.html) 2.0 или
  новее и `gcc`.

Установка `wl-clipboard`:

```sh
sudo dnf install wl-clipboard      # Fedora
sudo apt install wl-clipboard      # Debian, Ubuntu
```

## 3. Установка

### 3.1. Сборка

В корне проекта (рядом с `WaylandSwitcher.nim` и папкой `src/`):

```sh
nim c -d:release WaylandSwitcher.nim
```

Появится исполняемый файл `./WaylandSwitcher`. Ключ `--threads:on`
включён в файле `WaylandSwitcher.nims`, передавать его вручную не нужно.

> **Если сборка падает** с ошибкой вида
> `/etc/nim/nim.cfg(N, N) Error: unknown hint: LineTooLong`, дело не в
> проекте, а в несовместимости системного `/etc/nim/nim.cfg` с версией
> компилятора. Соберите с пропуском системного конфига:
> ```sh
> nim c --skipParentCfg -d:release WaylandSwitcher.nim
> ```

### 3.2. Установка бинарника и службы

```sh
./reinstall.sh
```

Скрипт при необходимости сам вызовет `sudo` и выполнит по порядку:

1. проверит, что рядом лежит исполняемый `./WaylandSwitcher`;
2. остановит службу, если она запущена;
3. скопирует бинарник в `/usr/local/bin/wayland-switcher` (через
   временный файл и `mv`, права `0755`, владелец `root:root`,
   `restorecon` для SELinux);
4. создаст systemd-юнит (`wayland-switcher -i`) и выполнит
   `daemon-reload`;
5. проверит наличие конфига и при его отсутствии запустит настройку
   (`wayland-switcher -c`);
6. включит автозапуск, запустит службу и проверит, что она работает; при
   ошибке покажет `status` и последние записи журнала.

Бинарник должен лежать в системном пути (`/usr/...`), иначе SELinux может
не разрешить его запуск от имени службы. Поэтому юнит нужно создавать
командой `-i` из установленной копии, как это делает скрипт, а не из
каталога сборки.

### 3.3. Установка вручную

```sh
sudo install -m 0755 WaylandSwitcher /usr/local/bin/wayland-switcher
sudo restorecon -v /usr/local/bin/wayland-switcher    # только с SELinux
sudo wayland-switcher -i
sudo wayland-switcher -c
sudo systemctl daemon-reload
sudo systemctl enable --now wayland-switcher
```

Юнит создаётся в `/lib/systemd/system/wayland-switcher.service` со
встроенной изоляцией (`ProtectSystem=strict`, `PrivateTmp=true`,
`NoNewPrivileges=true`) и автоматическим перезапуском при сбое.

## 4. Настройка

```sh
sudo wayland-switcher -c
```

Команда проводит через три шага.

### Шаг 1 — определение клавиатуры

Программа слушает **все** устройства `/dev/input/event*` и просит нажать
`Enter`. Устройство, на котором зафиксировано нажатие, сохраняется как
`keyboard`. Если физических клавиатур несколько, нажимайте `Enter` на той,
которой собираетесь печатать.

### Шаг 2 — клавиша переключения раскладки

Нажмите клавишу или сочетание из двух клавиш, которыми вы переключаете
язык ввода в системе: например, правый `Ctrl` или `Alt`+`Shift`
(зажимаются и отпускаются вместе). Эту же клавишу программа использует
при коррекции.

### Шаг 3 — клавиша коррекции

Клавиша, запускающая коррекцию. Рекомендуется `Pause`/`Break`: она редко
используется по другому назначению.

Конфигурация сохраняется в `/etc/wayland-switcher/default.conf`. Ожидание
нажатия в шагах 2 и 3 ограничено одной минутой.

Скан-коды клавиш можно посмотреть командой `sudo showkey`.

## 5. Использование

### 5.1. Коррекция набираемого текста

1. Напечатайте слово или фразу.
2. Если раскладка не та, нажмите клавишу коррекции:
   - **клавиша коррекции** — исправляется последнее слово (всё после
     последнего пробела);
   - **`Shift` + клавиша коррекции** — исправляется вся фраза (всё после
     последнего `Enter`).

Если перед этим вы стирали символы `Backspace`, это учитывается: стёртое
не возвращается.

Любая из клавиш `Tab`, `Ctrl`, `Alt`, стрелки, а также клик мыши сбрасывают
накопленный буфер: после них исправляется только то, что набрано заново.

### 5.2. Коррекция выделенного текста

1. Выделите текст:
   - протащите курсор с зажатой левой кнопкой (клик без протаскивания
     выделением не считается);
   - `Shift` + `←`/`→`/`↑`/`↓`;
   - `Shift` + `Home`/`End`/`PageUp`/`PageDown`;
   - `Ctrl`+`A`.
2. Нажмите клавишу коррекции.
3. Выделение заменяется перекодированным текстом. Направление (EN→RU или
   RU→EN) определяется по тому, каких букв в выделении больше.

Содержимое буфера обмена после коррекции остаётся таким, каким было до неё.

> Коррекция выполняется через виртуальные `Ctrl+C` и `Ctrl+V`, поэтому
> между выделением и нажатием клавиши коррекции **фокус должен оставаться
> в том же окне**.

### 5.3. Что снимает выделение

Программа считает выделение активным, пока вы не сделаете одно из
следующего. Тогда клавиша коррекции на него уже не подействует:

- кликнули мышью;
- нажали `Escape`, `Enter`, `Tab` или `Alt`;
- нажали стрелку без `Shift`;
- начали печатать обычный текст.

`Shift` и сама клавиша коррекции выделение не снимают.

## 6. Файл конфигурации

Путь: `/etc/wayland-switcher/default.conf`. Формат — `ключ=значение`,
значения можно заключать в двойные кавычки. Строки, начинающиеся с `#`,
считаются комментариями.

```ini
[WaylandSwitcher]
keyboard="/dev/input/event2"
mouse="/dev/input/mice"
layout-switch-key=97
replace-key=119
reverse-mode=false
delay=10
clipboard-tool=auto
```

| Параметр            | Значения                              | Назначение |
|---------------------|----------------------------------------|------------|
| `keyboard`          | путь `/dev/input/eventN`               | физическая клавиатура |
| `mouse`             | как правило `/dev/input/mice`          | мышь, по ней определяется протаскивание |
| `layout-switch-key` | скан-код или `код1+код2`               | клавиша или сочетание переключения раскладки |
| `replace-key`       | скан-код одной клавиши                 | клавиша коррекции |
| `reverse-mode`      | `true` / `false`                       | меняет местами «слово» и «фразу» |
| `delay`             | целое число 0–5000 (мс)                | пауза между событиями виртуальной клавиатуры; увеличьте, если приложение «не успевает» |
| `clipboard-tool`    | `auto` / `wayland` / `xclip` / `xsel`  | инструмент буфера обмена; `auto` выбирает первый найденный в `PATH`: `wl-paste`, `xclip`, `xsel` |

Обязательны `keyboard`, `mouse`, `layout-switch-key` и `replace-key`.
Изменить конфиг можно текстовым редактором от root либо повторным запуском
`sudo wayland-switcher -c`. После изменений перезапустите службу:
`sudo systemctl restart wayland-switcher`.

## 7. Параметры командной строки

```
wayland-switcher [параметр]
```

| Параметр            | Действие |
|---------------------|----------|
| `-i`, `--install`   | создать systemd-юнит |
| `-u`, `--uninstall` | удалить systemd-юнит |
| `-c`, `--configure` | интерактивная настройка (см. [раздел 4](#4-настройка)) |
| `-r`, `--run`       | запустить (так запускает юнит systemd) |
| `-d`, `--debug`     | запустить в терминале с подробным логом, без демонизации |
| `-o`, `--old-style` | запустить как классический Unix-демон (двойной fork, без systemd) |
| `-h`, `--help`      | справка |

Без параметров, а также с нераспознанным параметром выводится справка.

## 8. Обновление и переустановка

После изменения исходного кода или обновления версии:

```sh
nim c -d:release WaylandSwitcher.nim
./reinstall.sh
```

Конфиг при этом не затрагивается. Скрипт сам останавливает службу, заменяет
бинарник, обновляет юнит и снова запускает службу (см. [раздел 3.2](#32-установка-бинарника-и-службы)).
Компиляцию он не выполняет.

## 9. Диагностика проблем

### 9.1. Состояние службы и журнал

```sh
systemctl status wayland-switcher
journalctl -u wayland-switcher -b
```

Служба, которая не запускается, почти всегда жалуется на отсутствующий или
неполный конфиг, недоступное устройство ввода или `/dev/uinput`. Сообщение
об этом будет в журнале. Если служба упала три раза подряд за 10 секунд,
systemd перестаёт её перезапускать; после исправления причины выполните
`sudo systemctl reset-failed wayland-switcher` и запустите службу снова
(`reinstall.sh` делает это сам).

### 9.2. Режим отладки

```sh
sudo systemctl stop wayland-switcher
sudo wayland-switcher -d
```

В терминал выводятся все нажатия клавиш, события мыши и шаги коррекции.
Остановить — `Ctrl+C`.

### 9.3. Типичные проблемы

**Ничего не происходит при нажатии клавиши коррекции.**
Убедитесь, что служба запущена (`systemctl status`), что в конфиге указана
именно та клавиатура, на которой вы печатаете, и что `replace-key`
соответствует нужной клавише (`sudo showkey`). Запустите `-d`: при нажатии
должны появляться строки `input PAUSE down` и `input PAUSE up`.

**Коррекция выделения ничего не делает.**
- Выделение должно быть настоящим протаскиванием, а не кликом; движения
  короче 5 пикселей (`MouseDragThresholdPx`) не считаются.
- Между выделением и клавишей коррекции нельзя переключать окно.
- В `-d` ищите строку `выделение активно`.
- Если в логе есть `Ctrl+C не скопировал выделение, прерываем`, значит, в
  приложении выделения на самом деле не было; буфер обмена при этом
  остаётся нетронутым.

**В логе ошибки чтения или записи буфера обмена.**
Убедитесь, что установлен `wl-clipboard` (Wayland) либо `xclip`/`xsel`
(X11), и проверьте `clipboard-tool`. Без инструмента буфера обмена
коррекция выделения не работает, а коррекция набираемого текста (способ А)
работает: она буфер не использует.

**Заглавные буквы или знаки перекодируются неверно.**
Таблица (`src/layout.nim`) рассчитана на стандартную раскладку «русская»
(ЙЦУКЕН). На нестандартных раскладках, например «русская машинописная»,
знаки препинания могут не совпасть; буквы перекодируются верно всегда.

**Служба не останавливается или останавливается долго.**
Рабочие циклы проверяют сигнал завершения каждые 200 мс, остановка должна
занимать доли секунды. Если это не так, пришлите вывод
`journalctl -u wayland-switcher -b`.


## 11. Известные ограничения

- **Буфер обмена.** Коррекция выделенного текста идёт через CLIPBOARD
  (виртуальные `Ctrl+C` и `Ctrl+V`), а не через PRIMARY selection:
  GTK4-приложения, включая `gnome-text-editor`, не поддерживают PRIMARY на
  Wayland. На время коррекции содержимое CLIPBOARD временно заменяется, а
  затем восстанавливается. Побочный эффект: исправленный текст нельзя
  потом вставить повторно — в буфере уже лежит прежнее содержимое.
- **Защита от пустого выделения.** Перед `Ctrl+C` в CLIPBOARD записывается
  уникальный маркер. Если после `Ctrl+C` в буфере всё ещё маркер, значит,
  в приложении выделения не было: коррекция прерывается, буфер
  восстанавливается, в документ ничего не вставляется.
- **Языки.** Поддерживается только пара EN (QWERTY) ↔ RU (ЙЦУКЕН).
- **Фокус.** Между выделением и клавишей коррекции окно должно оставаться
  в фокусе. Программа не получает событий фокуса от композитора, поэтому о
  смене окна судит по косвенным признакам: клик мыши, `Tab`, `Alt`,
  `Escape`, `Enter`, обычный набор текста.
- **Мышь.** Протаскивание определяется по протоколу `/dev/input/mice`
  (PS/2, относительные смещения). Для большинства мышей этого достаточно,
  но на тач-устройствах работа может отличаться.
- **Сессия пользователя.** Для доступа к буферу обмена служба ищет среди
  процессов сессию обычного пользователя с `WAYLAND_DISPLAY` или `DISPLAY`
  и `XDG_RUNTIME_DIR`. При нескольких одновременных графических сессиях
  используется первая найденная.

## 12. Устройство программы

| Модуль | Назначение |
|--------|------------|
| `WaylandSwitcher.nim` | точка входа, параметры командной строки, режимы запуска |
| `src/types.nim` | типы и константы |
| `src/core.nim` | состояние, разделяемое потоками, ожидание ввода, логирование |
| `src/shellquote.nim` | экранирование строк для shell и systemd |
| `src/config.nim` | загрузка, проверка и запись конфигурации |
| `src/configure.nim` | интерактивная настройка |
| `src/install.nim` | systemd-юнит |
| `src/buffer.nim` | анализ буфера нажатий |
| `src/layout.nim` | перекодировка EN ↔ RU |
| `src/vkbd.nim` | виртуальная клавиатура (uinput) |
| `src/clipboard.nim` | буфер обмена сессии пользователя |
| `src/selection.nim` | коррекция выделенного текста |
| `src/mouse.nim` | поток мыши: клик или протаскивание |
| `src/daemon.nim` | главный рабочий цикл |

Главный поток читает события клавиатуры и ведёт буфер набора. Поток мыши
публикует последний жест (клик или протаскивание) в атомарную переменную,
которую главный поток забирает при очередном нажатии клавиши. Оба цикла
ждут ввод через `poll` с таймаутом 200 мс и потому завершаются сразу после
сигнала `SIGTERM` или `SIGINT`.
